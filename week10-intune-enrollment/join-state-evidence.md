\# Join State Evidence



\## AzureAdJoined



Value: YES



This shows the device is successfully joined to Microsoft Entra ID at the operating system level and is recognized as an organization-owned device.



\## WorkplaceJoined



Value: NO



This shows the device is not using the BYOD registration path and is not only workplace registered.



\## MDMUrl



Value: Blank



A blank MDMUrl indicates that Microsoft Intune enrollment did not complete successfully, so the device is not currently receiving Intune management policies.



\## TenantName



Value: Alexandria college



This identifies the Microsoft Entra tenant that the device is joined to and confirms which organization owns and manages the device identity.



\## DeviceId



Value: 0ba238a9-7fcf-45a3-85fc-e8359a588f39



The DeviceId is the unique identifier assigned to the device in Microsoft Entra ID and is used to track and manage the device in the tenant.
