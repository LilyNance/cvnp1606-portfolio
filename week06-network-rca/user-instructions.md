\# User Instructions for Resolving ACME Network Access Issues



If you cannot access the ACME intranet, shared drives, or other company resources, follow these steps before contacting the helpdesk.



\## Step 1: Check Whether the Internet Is Working



1\. Open your web browser.

2\. Visit one of the following websites:

&#x20;  - www.google.com

&#x20;  - www.microsoft.com

&#x20;  - www.bing.com

3\. If at least one website loads, your internet connection is working.

4\. If none of the websites load, stop here and contact the helpdesk.



\## Step 2: Run the Windows Network Troubleshooter



1\. Click the Start button.

2\. Click Settings.

3\. Click Network \& Internet.

4\. Click Status.

5\. Select Network Troubleshooter.

6\. Follow the instructions displayed on the screen.

7\. If Windows finds a problem, allow it to apply the recommended fix.



\## Step 3: Restart Your Network Connection



1\. Press the Windows key and the R key at the same time.

2\. Type `ncpa.cpl` and click OK.

3\. Find the connection named Ethernet.

4\. Right-click Ethernet and select Disable.

5\. Wait 10 seconds.

6\. Right-click Ethernet again and select Enable.

7\. Wait one minute for the connection to reconnect.



\## Step 4: Restart Your Computer



1\. Save any work you have open.

2\. Click the Start button.

3\. Click Power.

4\. Select Restart.

5\. Wait for the computer to restart completely.



\## Step 5: Test ACME Resources



1\. Open your web browser.

2\. Try accessing the ACME intranet website.

3\. Try opening your shared drives.

4\. Verify that company resources are available.



\## When to Contact the Helpdesk



Stop troubleshooting and contact the helpdesk if:



\- You cannot open any websites.

\- The problem comes back after following these steps.

\- You see a yellow warning icon on the network connection.

\- You receive repeated network error messages.

\- You still cannot access ACME resources after completing all the steps in this guide.



When contacting the helpdesk, tell the technician which steps you completed and describe any error messages you saw. This will help us resolve the issue more quickly.
