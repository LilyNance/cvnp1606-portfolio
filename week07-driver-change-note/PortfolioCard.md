# Portfolio Card



## About Me



I am developing hands-on IT support and cybersecurity skills through Windows administration labs, virtual machine projects, troubleshooting exercises, and technical documentation. These labs help me gain experience with the tools and procedures commonly used by help desk technicians and IT support professionals.



## What I Learned



Throughout these labs, I learned how important planning, documentation, and verification are in IT support. Creating a clean Windows 11 virtual machine taught me the value of having a reliable baseline that can be restored whenever testing or troubleshooting is needed.



I also improved my documentation skills by creating support guides and testing instructions on a live system before sharing them. This helped me understand that good documentation should be accurate, easy to follow, and verified rather than based on memory alone.



In addition, I gained hands-on experience using PowerShell and Windows administrative tools to manage user accounts, review permissions, and audit administrator access. Learning how to apply the principle of least privilege showed me how proper account management can help protect systems from accidental changes and security risks.



This week, I learned how to use Task Manager, Resource Monitor, and PowerShell to troubleshoot slow Windows systems. Capturing before and after metrics showed me how important it is to use evidence when diagnosing performance issues and verifying that a remediation was successful.



This week, I also learned how to use Device Manager and PowerShell to identify devices that were not functioning correctly, collect hardware information, review driver details, and determine the safest remediation option. I gained experience documenting the before state, evaluating rollback options, verifying a successful repair, and creating a rollback plan that another technician could follow if the change needed to be reversed.



These experiences helped me become more confident with Windows administration, troubleshooting, performance analysis, device and driver management, and documenting technical work in a professional and organized manner.
