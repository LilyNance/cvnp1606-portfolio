\# Least Privilege Access Memo



\*\*To:\*\* IT Management Team



\*\*From:\*\* Lily Nance



\*\*Subject:\*\* Least Privilege Account Review





As part of this account audit, I reviewed local user permissions and confirmed that the Seasonal-staff account was set up as a standard user and not a member of the Administrators group. The goal was to follow the principle of least privilege by making sure users only have the access they need to do their jobs.



I believe local administrator access should only be given when it is necessary for a person's job responsibilities. For example, IT technicians may need administrator rights to install software, troubleshoot operating system issues, manage services, or configure hardware. However, users who only need access to business applications should be limited to standard users. Giving unnecessary administrator access can increase security risks and allow accidental changes to the system.



If a user requests administrator access, I would review the reason for the request before granting additional permissions. If the task does not clearly require elevated access or if another solution may be available, I would escalate the request to an IT manager or system administrator. I would provide details about the user's role, the task they need to complete, and the business reason for requesting access. This helps ensure that access is granted based on business needs rather than convenience.



If temporary elevated access is approved, there should be documentation supporting the request. This should include the business justification, the specific task being completed, the length of time access is needed, who approved the request, and any alternative solutions that were considered. An audit trail should also be maintained to confirm that the access was used correctly and removed when it is no longer needed.



Following the principle of least privilege helps protect systems, reduce security risks, and ensure users have the right level of access to perform their work safely and sufficiently.
