# Support Note Examples



## Example 1: Resolved User Navigation Issue



User could not locate Mouse Pointer settings after the Windows 11 refresh. Guided user to Settings > Accessibility > Mouse pointer and touch. User successfully increased pointer size and confirmed improved visibility. Issue resolved.



---



## Example 2: Escalation Required



User attempted to uninstall Xbox Live but the Uninstall option was unavailable. Verified the application was managed by organizational policy. Escalated ticket to the desktop support team for administrator review and approval.



---
